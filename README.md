# ImagoHub

Projeto Flutter com as 11 telas do wireframe, busca real na Unsplash e contas persistentes.

O acesso começa no login. Cadastro concluído entra na galeria; perfil e configurações exigem uma conta autenticada.

Versão 1.0.2: perfil sem abas duplicadas, nome de usuário livre no cadastro e no servidor, senha editável, busca sem valores prontos, seletor de cor e categorias clicáveis.

Instruções completas em português: [LEIA-ME.md](LEIA-ME.md).

Abra `ImagoHub.code-workspace` no VS Code e execute **ImagoHub · Chrome** com F5, ou:

```bash
python scripts/run.py --device chrome
```
